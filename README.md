# 🐱 Miau Café

Projeto desenvolvido na disciplina de **Construção de Páginas Web**, do curso de Tecnologia em Sistemas para Internet – IFAC.

O Miau Café é um site responsivo composto por múltiplas páginas, desenvolvido para aplicar conceitos de desenvolvimento Front-End com **HTML, CSS e JavaScript**.

## 💻 Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- CSS Grid
- LocalStorage

## ⚙️ Funcionalidades

O projeto conta com:

- Navegação responsiva e menu hambúrguer;
- Formulário com validação de CPF e telefone via JavaScript;
- Manipulação do DOM e eventos;
- Modo escuro com preferência salva no LocalStorage;
- Carousel de imagens;
- Layout utilizando CSS Grid;
- Elementos SVG;
- Integração de vídeo do YouTube e conteúdo via iframe;
- Uso de Bootstrap para responsividade e componentes.

## 🎓 Contexto

Trabalho acadêmico desenvolvido na disciplina de **Construção de Páginas Web – IFAC**, com foco na aplicação prática de tecnologias Web.
