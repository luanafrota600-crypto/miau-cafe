# 🐱 Miau Café

Projeto desenvolvido na disciplina de **Construção de Páginas Web**, com o objetivo de aplicar na prática conceitos de desenvolvimento Front-End utilizando **HTML, CSS e JavaScript**.

O projeto consiste em um site responsivo para o **Miau Café**, um café temático com gatos, apresentando informações sobre o estabelecimento, cardápio, gatos, formas de visitação e contato.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- CSS Grid
- LocalStorage
- SVG
- Iframe

## 📄 Páginas do projeto

O site é composto por diferentes páginas:

- **Home** – apresentação do Miau Café e principais informações;
- **Cardápio** – apresentação dos produtos disponíveis;
- **Gatos** – apresentação dos gatos e carousel de imagens;
- **Visitar** – informações e orientações para visitação;
- **Contato** – formulário de contato e localização;
- **Sobre** – informações sobre o projeto e o estabelecimento.

## ⚙️ Funcionalidades

Durante o desenvolvimento foram implementados diferentes recursos de HTML, CSS e JavaScript, entre eles:

- Menu de navegação responsivo;
- Menu hambúrguer para dispositivos móveis;
- Dropdowns de navegação;
- Carousel de imagens;
- Manipulação do DOM com JavaScript;
- Eventos em JavaScript;
- Modo escuro com preferência armazenada em `localStorage`;
- Exibição de imagens em modal;
- Formulário de contato;
- Validação de CPF em JavaScript;
- Validação de telefone brasileiro;
- Formatação automática de CPF e telefone;
- Layout responsivo;
- Utilização de CSS Grid;
- Elementos gráficos utilizando SVG;
- Incorporação de vídeo do YouTube;
- Incorporação de conteúdo externo através de iframe;
- Utilização do Bootstrap 5 em parte da aplicação.
